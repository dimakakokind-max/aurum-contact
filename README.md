# AURUM | Contact Form 📩

Стильная форма обратной связи, созданная в эстетике премиального бренда **AURUM**. Проект представляет собой отдельную страницу (или блок) для сбора заявок на разработку.

## ✨ Особенности

*   **Единый стиль AURUM:** Темная тема, золотые акценты, шрифт Cormorant Garamond и эффект матового стекла (Glassmorphism).
*   **Отправка на EmailJS:** Работающая форма, которая отправляет письмо прямо на ваш Gmail без использования серверов и баз данных.
*   **Валидация:** Проверка обязательных полей (имя, email, сообщение).
*   **Интерактивность:** Плавные анимации при фокусе на полях ввода и при нажатии на кнопку.
*   **Адаптивность:** Форма корректно отображается на мобильных устройствах.

## 🛠️ Технологии

*   HTML5
*   CSS3 (Flexbox, Backdrop-filter)
*   JavaScript (Vanilla JS, EmailJS API)

## 🚀 Как использовать

1.  Скопируйте код формы и скрипта.
2.  Вставьте его в свой HTML-файл.
3.  Замените `SERVICE_ID`, `TEMPLATE_ID` и `PUBLIC_KEY` в скрипте на свои значения из панели EmailJS.
4.  Готово! Заявки будут приходить вам на почту.
